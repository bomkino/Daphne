# Daphne's story film

Read `notes/handover.md` first, every session and after every compaction. Keep `notes/tasks.md`, `notes/decisions.md`, `notes/kay-words.md`, `notes/learnings.md` and `notes/journey.md` current as you work. The files win over any summary.

When compacting, keep the list of changed files, the check to run (`npx tsc --noEmit -p .`, then a contact sheet with `npm run sheet`), the open decisions, and the path `notes/handover.md`.

This film was started from pitch.dog's Remotion kit (bomkino/remotion-starter-kit); its AGENTS.md holds the studio's working agreements and public-voice rules, which apply here. `README.md` says how the film is built; `NARRATION.md` is Manali's script.
